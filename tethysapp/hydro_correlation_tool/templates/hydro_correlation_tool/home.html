Hydro-Correlation Tool Help
About this project

Because there are three different datasets for the same rivers, three IDs point at the same reach. This makes it impossible to tell which reach ID corresponds to which gage. The purpose of this app is to build a table that maps all three corresponding IDs to one another through human verification.

Getting help

To see the app layout, click "Take the tour". If you would like the workflow instructions, select the 3 lines in the upper left-hand corner. For further assistance or to report a bug, email ghover@aquaveo.com. Thanks!
